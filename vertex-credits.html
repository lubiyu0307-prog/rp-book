開始之前

這次申請的是 Google Cloud 免費試用抵免額：效期三個月、額度台幣九千多（畫面顯示 NT$9,564，即 $300 美元的換算）。期限內用 Vertex AI 都算它出錢，額度用完或到期就自動停用。只要你的 Google 帳號還沒申請過免費試用，就能領一次。

第一部：開通免費試用

四步、約五分鐘。

1

從官網進入免費試用

cloud.google.com → 免費試用

用你的 Google 帳號登入後，開 cloud.google.com，按「免費試用」。頁面上就寫著「取得價值 $300 美元的抵免額」。

2

帳戶資訊

免費試用 → 步驟 1／2

國家／地區選「台灣」，右側就是三大保證：$300 抵免額、90 天、不會自動收費。看完按「同意並繼續」。

3

付款驗證與稅務資訊

免費試用 → 步驟 2／2

填聯絡資訊、新增付款方式（就是驗證身分用的那張卡）。中間會跳出「台灣稅務資訊」視窗——個人用戶稅籍選「未登記稅籍的個人」→ 儲存。最後按「開始免費試用」。

4

開通完成

Console 歡迎頁

看到歡迎頁就成了：抵免額 NT$9,564（＝$300 美元）、90 天倒數開始、系統自動幫你建了一個「My First Project」專案。頂部橫幅也再次確認：額度用盡後才「按照用量收費」，而且前提是你手動升級。

第二部：解鎖並建立 API 金鑰

Google 對新帳號預設鎖著「建立 API 金鑰」，先開鎖、再拿鑰匙。

5

找到那條封鎖政策

IAM 與管理 → 組織政策

在政策清單的「篩選條件」框（表格正上方那行，有漏斗圖示的，不是頁面頂部的搜尋列）輸入 apikey，自動完成會直接跳出目標：

選它之後清單只剩一條「Block service account API key bindings」，狀態「已啟用」。點進去。

6

權限不足？讓 Google 自己幫你補

政策詳細資料 → 修正存取權

點進政策詳細資料，會發現「管理政策」是灰色的——提示你缺 orgpolicy.policies.update 等權限。別慌，點提示框裡的藍色「修正存取權」。

它會自動算出你缺什麼、該補哪個角色（「組織政策管理員」roles/orgpolicy.policyAdmin）、要授在哪裡（你的組織）。確認資訊沒錯，按「授予存取權」——一鍵完成，不用自己去組織層級翻 IAM。

等一兩分鐘讓權限生效，重新整理頁面，「管理政策」的鉛筆就亮了。

7

在你的專案上覆寫、關閉它

政策詳細資料 → 管理政策

點「管理政策」，政策來源選「覆寫父項政策」→ 規則區「新增規則」→ 強制執行選「停用」→ 按規則卡的「完成」：

最後按「設定政策」，跳出確認視窗再按一次「設定政策」。規則顯示「未強制執行」就成功了——而且只解鎖這一個專案，組織其他地方維持上鎖，風險面最小。

8

建立你的 API 金鑰

Vertex AI → 設定 → API 金鑰

解鎖後，Console 首頁的產品卡就會出現建立金鑰的入口（「建立 Gemini API 金鑰」／「取得 Agent Platform API 金鑰」都通到同一處）：

進到設定頁，如果上方有黃色的「啟用 API」橫幅，先按一下把 API 打開（幾秒就好）：

然後就是收穫時刻——之前的封鎖警告消失了，「Create API Key」可以按了：

按下去、幫金鑰取個名字、建立。畫面會彈出你的金鑰——一串長長的英數字串。當場按複製、收好它。之後隨時可以回這個清單按「顯示金鑰」再看一次。

收好你的金鑰

這串字串＝你的抵免額。誰拿到，誰就能花你的額度。

  • 只貼進你信任的應用，不要傳給任何人、不要貼到公開的聊天室或社群、不要提交進程式碼庫。
  • 建議回金鑰設定頁幫它加上 API 範圍限制（限定只能呼叫 Vertex AI），就算外流傷害也有限。
  • 懷疑外流就立刻刪掉重建——金鑰可以隨時作廢再生，不用心疼。
  • 額度用到哪了，隨時回 Console 首頁看那個圓圈（或 帳單 → 總覽）。90 天到期或額度歸零，帳戶自動停用，不會偷偷開始收費。
這份指南以 Google Cloud Console 2026-07 版介面、台灣帳號流程為準。日後選單位置可能微調，但限制 ID 不會變：認 iam.managed.disableServiceAccountApiKeyCreation 就對了。
